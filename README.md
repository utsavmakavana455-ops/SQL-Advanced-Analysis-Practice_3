# SQL Advanced Analysis Practice

## 📊 Project Overview

This project contains **6 practical SQL problems (Questions 16–21)** using a 100-row e-commerce orders dataset.

The focus is on advanced SQL techniques used in real-world data analysis, including **window functions, subqueries, customer analysis, date functions, and revenue analysis**.

## 🗂️ Questions Covered

### 16. Top 3 Highest-Value Orders by City

Find the top 3 highest-value orders within each city.

**Concepts:** `ROW_NUMBER()`, `PARTITION BY`, Window Functions

### 17. Customer Sales Contribution

Calculate each customer's total spending and percentage contribution to overall sales.

**Concepts:** `SUM()`, Subquery, Percentage Calculation

### 18. Previous Order Analysis

Show each customer's current order, previous order amount, and difference between the two.

**Concepts:** `LAG()`, `PARTITION BY`, Window Functions

### 19. Highest-Spending Customer by City

Find the customer with the highest total spending in each city.

**Concepts:** `RANK()`, `PARTITION BY`, `GROUP BY`

### 20. Monthly Sales Report

Create a monthly report containing total orders, units sold, total sales, and average order value.

**Concepts:** `DATE_FORMAT()`, `GROUP BY`, Aggregate Functions

### 21. Above-Average Product Revenue

Find products whose total revenue is higher than the average revenue per product.

**Concepts:** Subqueries, `HAVING`, `AVG()`, `SUM()`
